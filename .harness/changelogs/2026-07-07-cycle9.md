# Math Guardian v3.5 — audit cycle 8 (2026-07-07)

## Cycle 9 — 4 fixes + 14 test assertions (T21)

Snapshot / Profile resilience — 防 localStorage 各種 failure mode 對中度 SEN 學生造成 silent breakage。

| Fix | Severity | 一句總結 |
|---|---|---|
| **F-09** | P0 | `Snapshot.load()` corrupt-state guard — validate 6 個 required keys (`state / state.bossHp / state.bossMaxHp / state.teams / state.castle / settings / savedAt`)。missing/corrupt 即 return null，trigger 新局。同時 `Snapshot.resume()` 加 age hint：snapshot 超過 6 小時就 `FX.screenAlert` 通知，避免 silent resume 一個過夜 session。 |
| **F-10** | P1 | `Snapshot.flush` quota-aware fallback — 加 `_quotaExceeded` flag。STORAGE.save return false 就 set flag，往後 autosave 提早 return 唔再 spam logging，in-memory state 照玩但 reload 唔可以 resume。`startGame()` 重新 reset flag，新局再嘗試 save。對 quota-exceeded 嘅老師/家長：遊戲唔會 crash，silent 退化到 in-memory。 |
| **F-11** | P1 | `Profile.load()` lazy-migration — 老 user localStorage schema drift：{...spread} 只 overwrite 已有 keys，但缺 `reactionByType / streakByType / errorPattern / statsByType` 嘅 user 直接 .push() 會 crash。新增 9 個 field 嘅 default init，全部走 `!field || typeof !== 'object/object'` check + `Array.isArray()` guard。 |
| **F-12** | P2 | `Snapshot.resume()` review + current sanitization — `state.review` 個別 item 缺 `type/answer` 會喺 `UI.renderReview()` crash。新做法 `filter(q => q && typeof === 'object' && q.type && q.answer !== undefined)` 提早 drop malformed。同樣 `state.current[team]` per-team check，避免 resume 一個半截 question 狀態。 |

## 對中度智障學生嘅 impact

- **F-09 嘅 6 小時 age hint** — 學生 reload 唔會無聲無息 resume 過夜 session；老師/家長會見到提示，可以選擇重新開始。
- **F-10 嘅 quota fallback** — 老師電腦 quota 滿 (典型：十幾個 profile 同存) 唔會 crash，in-memory 玩到完場。
- **F-11 lazy-migration** — 唔可以因為 schema drift 整爛個 student profile；新 install 老 user 唔需要 reset。
- **F-12 review sanitization** — UI 唔會見到「undefined 題目」，render 一定乾淨。
