## What was implemented

### `Adaptive.recommendWithHistory(team, n=5)` — cross-session weighted

Spec (v35-roadmap §2) — combine current session (60%) + last 10 sessions (40%)：

```
weightedAcc = curAcc * 0.6 + histAcc * 0.4
```

新增 3 個 helper：
- **`_aggregateHistoryAccuracy(window)`** — 攞 HISTORY 嘅 last N sessions，
  aggregate per-type c/w，return `{ [typeId]: { accuracy, samples } }`
- **`_weightedTypeAccuracy(typeId, histAcc)`** — 60/40 weighted formula，
  處理 4 種 null/non-null 組合（cold start / 純 current / 純 history / mixed）
- **`recommendWithHistory(team, n)`** — 5 types ranked by:
  1. priority 升冪 (1 weak → 5 mastered)
  2. score 降冪 (低 accuracy 排先)
  3. typeId 字典序 (stable tiebreaker)

Cold start → 5 easiest types by `reg.difficulty` (spec cold-start acceptance)。
Streak ≥ 3 加分 (momentum tiebreaker, 跟 AUDIT11 一致)。

### `archiveReport()` per-type snapshot

舊版只 record `total: { c, w }` aggregate，cycle 16 加 `perType: { [typeId]: { c, w } }` —
只 snapshot 進行中 selected types（settings.types），避免 cold start 推薦時
混入其他 type 嘅 zero-accuracy noise。

### UI: `#recommend-chips` row

獨立 row 喺 `#type-picker` 下面：
- **`<div id="recommend-chips" role="group" aria-label="自動推薦題型">`**
- 每個 chip: `<button class="rec-chip" data-rec-type="..." role="checkbox" aria-checked="...">`
- 已選嘅 type 顯示 `.rec-selected` 綠色 border
- ✨ 標籤 prefix: `✨ 建議：` 跟 chip button

**Tap handler**：
- 已選 → splice 出 (但保留至少 1 個 type, 防 stale UI)
- 未選 → push 入
- 同步：renderTypePicker + updateTypeCount + renderRecommendChips + Audio.tick

### CSS (新增 `rec-chip` 樣式)

- `linear-gradient(135deg, amber/purple)` 背景 — 金色 + 紫色混合
- `:hover` 加深 gradient，`:active` scale(0.95)
- `.rec-selected` 改綠色 (`#22c55e` border)
- `prefers-reduced-motion: reduce` 關 transition

### Setting: `Game.settings.recommendationEnabled` (default true)

- 跟 `adaptiveEnabled` 分開 — 老師可單獨關 chips row 而保留 type-picker 嘅 ✨ 標記
- 自動 merge 入 `Snapshot` (cycle 12+ 嘅 `{ ...Game.settings, ...s.settings }` spread)
- Lazy-migration: 老 user 嘅 settings 冇呢個 field → default true

### Teacher modal: `td-recommendation-enabled` checkbox

- `aria-describedby` 描述 cross-session weighted formula
- `onchange` toggle + `renderRecommendChips()` + announceToA11y
