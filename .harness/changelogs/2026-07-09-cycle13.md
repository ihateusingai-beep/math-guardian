## Validators 設計理由

對中度智障學生嘅題目一定要 sanitized，老師唔可以塞 garbage 入 bank 影響
rotation 70%/30% (cycle 11 ship)。6 種 layout 各自 pure validator：

- **numeric** — `answer` 必須 finite number
- **parts-emoji** — numeric + range 1-10 integer (count10/double 範圍)
- **sym-button** — answer ∈ `<`/`>`/`=`
- **clock** — numeric + range 1-12 integer (whatTime 範圍)
- **shape** — answer ∈ 4 shapes + `options` 必含 answer (e.g. option 無 answer 就 0% 揀中)
- **order** — answer 必係 length-3 ascending + distinct array + `displayNums` length-3

每個返 `{ok, error, normalized?}` shape。Validator error message 用粵語 / 中文
夾雜 (e.g. 「clock answer 必須是 1-12 整數」)，`announceToA11y` 同步
screen-reader 講返。

## Dedupe + Cap

- **Fingerprint**：`${parts.join('')}::${JSON.stringify(answer)}`。同 entry 撞即 skip。
  Shape 同 text 一樣但 answer 唔同 (e.g. 圓形 vs 方形) 就唔撞，允許。
- **Cap**：每 type 20 條，default seed 10 + 10 user。超 reject `capped: true`。
  Counter 喺 inventory section header 即時 update。
